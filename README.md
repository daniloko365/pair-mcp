# Pair

Pair — локальное приложение для macOS, которое добавляет совет моделей и
совместную работу Codex/Claude в **ваш привычный чат**. Вы выбираете проект и
модели в небольшой панели; Pair запускает официальных агентов, а исходный чат
сводит результаты и проверяет файлы и тесты. Это не ещё один чат-сайт.

**За минуту:** [подключить Pair и вызвать его из нового чата Codex](QUICKSTART.md).
У Pair нет аккаунта или кошелька; значок в строке меню — дополнительный способ
открыть обычное Mac-приложение из Dock.

Это первая **macOS-бета**, а не универсальный агентный движок. API-запросы оплачиваются
вашим поставщикам; бесплатная программа не делает модели бесплатными.

**Скачать:** [Pair 1.0.0 — технический prerelease](https://github.com/daniloko365/pair-mcp/releases/tag/v1.0.0)
для Apple Silicon Mac. Архив приложения не нотариализован Apple и требует
обычного подтверждения открытия в macOS; это пока не установка «в один клик».
SHA-256 архива `Pair-1.0.0-unnotarized-macos-arm64.zip`:
`9307f226241056dcf5404abaf0de5274bf683a36e9eb14cf0c6c06721049e0e4`.
Начните с [быстрого старта](QUICKSTART.md); разработчики также могут
[собрать Pair из исходников](#исходники-и-проверка-сборки).

## Начать пользоваться

1. Поместите `Pair.app` в стабильное место, например `~/Applications`, до
   подключения клиентов. Откройте Pair из Dock или через Spotlight
   (⌘Пробел → Pair). В чате с
   подключённым Pair скажите «Открой настройки Pair» — MCP вызовет
   `pair_open_settings`. Значок в строке меню дополнительный; синяя декоративная
   картинка внутри окна удалена. Закрытие окна не отменяет работающие задачи.
2. В **Подключениях** подключите установленный официальный Codex и/или Claude.
   Pair добавляет только свой MCP и skill `pair-work`; основной провайдер клиента
   и другие плагины не заменяются. После подключения или обновления Pair нужен
   новый обычный чат: уже открытый чат может держать старый MCP-процесс.
3. Для API нажмите **Добавить API**: название, адрес, протокол и ключ. Ключ вводится
   один раз и хранится в macOS Keychain, а не в файле настроек. После сохранения
   каталог автоматически загружается при выборе этого API или открытии его
   настроек. «Обновить» повторяет загрузку вручную; если сервер не предоставляет
   каталог, укажите точные ID вручную. Генерация для загрузки каталога не запускается.
4. В **Совете** выберите участников, модели и при необходимости резервы. В **Паре**
   выберите проект, которому разрешено передавать задачи, и настройки партнёров.
   Нажмите **Сохранить** или Cmd-S. Следующий вызов получает новые настройки;
   запущенные задачи сохраняют свой снимок конфигурации.
5. В новом чате вызовите `$pair-work` и задайте конкретный результат, например:

   > Используй Pair: передай Codex создание небольшого калькулятора в выбранном
   > проекте. Получи полный результат, проверь изменения и запусти его тесты.

   Или:

   > Используй сохранённый совет Pair для независимого ревью этого решения.
   > Покажи мнения, ошибки участников и итог с оставшимися противоречиями.

Skill не должен вызываться на каждом сообщении. Для смены состава совета
откройте Pair из Dock или попросите агента открыть настройки через
`pair_open_settings`. Если Codex спросит разрешение на вызов инструмента Pair,
подтвердите его для нужной задачи: в режиме запрета всех разрешений делегирование
не начнётся. Такое подтверждение не является согласием на платный API-вызов.

По умолчанию список исключает явно нетекстовые и batch-варианты; «Весь каталог»
возвращает полный список. Сохранённая/ручная модель не исчезает при фильтрации.
Сначала явно выберите «Источник», затем используйте отдельный «Поиск модели»
в каталоге этого источника и выберите модель. Ввод имени другого источника в
модельный поиск даст подсказку, но не переключит маршрут и не запустит платный
вызов. Enter сам источник не меняет. Для нового API модель не выбирается
автоматически. Сохранённая модель остаётся видимой даже без совпадений поиска.
Неизвестная совместимость не считается запретом, но отмечается предупреждением.
Batch — асинхронный API, не обычный чат; это не новая возможность Pair.
Если поставщик не объявил допустимые уровни reasoning, панель предлагает явный
выбор с предупреждением. «По умолчанию поставщика» не отправляет effort; уже
сохранённое значение не сбрасывается автоматически. При явно пустом enum новые
уровни не выдумываются. Ошибка загрузки не вызывает бесконечных повторов.

С клавиатуры: Cmd-1/2/3 — Совет/Пара/Подключения, Cmd-S — сохранить,
Shift-Cmd-N — добавить участника, Cmd-Z — отменить изменение, Cmd-W — закрыть окно
без отмены задач. Удаление участника доступно и через меню «Совет». Закрытое окно
сохраняет черновик; при выходе из панели с несохранёнными данными появится обычный
выбор Save/Discard/Cancel. Задания backend при этом продолжаются.

Без подписки Claude можно использовать Codex по подписке и Claude через API:
попросите в чате «Передай Claude через OpenRouter API задачу в выбранном проекте,
модель anthropic/claude-opus-5.5». Агент должен явно выбрать `mode=api`,
`providerId=openrouter`, а не незаметно заменить подписку оплатой API.

Приложение необходимо разместить в окончательной папке **до** подключения клиентов.
После перемещения app переподключите Pair: MCP использует конкретный путь backend.
Установка официальных Codex/Claude и вход в подписку выполняются их собственными
средствами. Pair не собирает и не проксирует подписочные токены.

## Что делает бета

- Несколько OpenAI-совместимых, Anthropic и Jev-подключений, каталог/поиск моделей
  и ручные ID. Это поддерживаемые протоколы, не обещание любого API.
- Независимые мнения участников совета, реальный источник/модель, ошибки и порядок
  резервов. По умолчанию итог составляет агент в исходном чате из полученных мнений;
  отсутствие итога не выдаётся за законченную консультацию.
- Официальные CLI Codex/Claude для задач с разрешённым проектом, сохранённым job ID,
  полным результатом, файлами и адресной отменой. Pair координирует, но не заменяет
  их агентный движок. Чат может передать работу первому агенту, дождаться файлов
  и тестов, затем дать второму доступ на чтение для проверки реального diff.
  Pair не запускает двух писателей в пересекающихся проектах одновременно и
  не делает автоматический merge. Повторная проверка тем же поставщиком —
  самопроверка, не независимое мнение другой модели.
- Доступное состояние авторизации, моделей, квот и skills; неизвестные данные
  не считаются нулевыми или бесконечными. Метаданные имеют время обновления.
- Опциональные typed-проверки и ранжирование Jev. Исходные данные остаются доступны;
  результат — рекомендация, не доказательство истинности. Пользовательские явные
  и обязательные skills не отключаются. Jev отправляет данные своему API и может
  стоить денег; выигрыш на конкретной задаче требует измерения.

Для такого отбора попросите в обычном чате: «Используй Pair/Jev, выбери нужные
необязательные справочные блоки для этой задачи, сохрани обязательные условия и
исходники, затем передай выбранную справку Codex». Это явный инструмент агента,
не скрытое отключение skills. В реальном локальном тесте справка уменьшилась
2034→929 байт; экономия токенов/денег всей задачи этим не доказана.

API-ключи, вопросы и данные отправляются только явно настроенным поставщикам.
Собственный/локальный endpoint включайте лишь если ему доверяете. Pair не принимает
адрес API из ответа модели и не выставляет настройки в публичную сеть.

## Лимиты и ошибки

Выходные токены, время и API-бюджет задаются в дополнительных настройках совета.
Пустое поле означает отсутствие собственного лимита Pair, но квоты и максимумы
поставщика сохраняются. Подписочному CLI нельзя обещать тот же жёсткий предел
выходных токенов, что отдельному API-запросу; неподдерживаемые параметры обозначаются.
Claude CLI принимает максимум выходных токенов для большинства запросов;
это не общий предел всех шагов или гарантия счёта. Codex CLI такого жёсткого
параметра не предоставляет. [Официальные параметры Claude](https://code.claude.com/docs/en/env-vars).

Для Clodex применяется 15-секундное ожидание первого полезного вывода. Резерв не
подменяет уже начавшийся ответ. Неизвестная стоимость не превращается в $0: при
конечном бюджете запрос без проверяемой оценки отклоняется, неопределённое списание
остаётся зарезервированным, скрытые платные повторения не запускаются.

Для участника совета Codex по подписке сохранённый API-резерв включается только
после подтверждённого официальным app-server отказа по квоте/скорости/перегрузке
до полезного ответа. Ошибки входа, permissions, отмена, timeout и текст модели
не являются таким разрешением. Проценты квоты тоже не запускают платный резерв.
Эта ветка относится только к read-only мнению в совете; кодинг-задачи продолжают
работать через обычный официальный exec. Для Claude автоматический подписочный
fallback не заявлен без надёжного машинного сигнала. [Официальный протокол ошибок](https://learn.chatgpt.com/docs/app-server).

Официальный API-режим CLI не предоставляет проверяемый жёсткий предел счёта через
произвольный endpoint. Такой job с конечным обязательным API-бюджетом отклоняется;
снятие ограничения — явный выбор пользователя, не обход защиты. Наблюдаемый таймаут
не означает завершение работы: проверяйте тот же job ID, а не запускайте дубль.

## Поддержка и честные ограничения

- Первая физическая платформа — Apple Silicon Mac. Сборка имеет deployment target
  macOS 13, но поддержка каждой старой версии macOS отдельно не подтверждена.
  Windows, Linux и Intel Mac пока не приняты реальными тестами.
- Бета подписана ad-hoc, **не notarized**. Это не публичный подписанный релиз.
  Не требуется отключать Gatekeeper для всей системы; если ОС запрещает открытие,
  используйте обычное локальное разрешение в Privacy & Security либо сборку из кода.
- Подписка Claude отсутствует у первого тестировщика. Двухподписочная приёмка пока
  непроверена; Claude API и Codex-подписка не подменяют её.
- Режим Claude-рецензента `read-only` ограничивает встроенные инструменты чтением
  файлов разрешённого проекта; тесты и diff повторно проверяет исходный чат.
  Это не гарантия «ноль записей на всём Mac»: официальный Claude CLI может
  сохранять собственное служебное состояние. Для такого режима нужен Claude
  Code 2.1.248 или новее, поддерживающий `--restricted`.
- Рабочий каталог и штатные permissions CLI не являются изоляцией от злонамеренного
  агента того же пользователя на всём компьютере. Не передавайте непроверенным
  задачам основной проект с секретами.
- Не все API имеют одинаковые reasoning, цены, каталог и протоколы. Нет автоматического
  обещания «экономии Jev» или идентичности выбранного имени модели её самоописанию.
- Старый OmniRoute и VPS не мигрируются, не отключаются и не нужны для локальной панели.
- Claude JSON-result не даёт полного manifest изменённых файлов: исходный чат
  должен независимо проверить указанные пути. Полные CLI-результаты сохраняются.
  Codex API-mode environment isolation для чужих MCP не проверена; базовая
  проверенная схема — Codex-подписка плюс Claude/OpenRouter API.
- У официального CLI нет искусственного шага остановки Pair, но экстремально
  большой непрерывный вывод может исчерпать память локального worker. Это
  известный риск технической беты, а не обещание неограниченной RAM.

Команды проверки сборки приведены ниже. Публичный prerelease прошёл локальную
проверку архива и практический сценарий в новом чате; установка на чужом Mac
остаётся непроверенной.

## Исходники и проверка сборки

Для разработки нужны Python 3.12+, `uv` и Xcode Command Line Tools. Из корня:

```sh
uv sync --frozen
uv run pytest -q
PAIR_RELEASE_STAGE=$(mktemp -d /private/tmp/pair-release.XXXXXX)
PAIR_BUNDLE_OUTPUT="$PAIR_RELEASE_STAGE/Pair.app" sh scripts/build-release.sh
uv run python scripts/check-release.py --bundle "$PAIR_RELEASE_STAGE/Pair.app"
```

Собирайте кандидата во временной папке и перемещайте только проверенную сборку
в `~/Applications`: обычный вывод в `dist/Pair.app` вместе с установленной
копией снова создаст дубликаты в Spotlight. Не удаляйте текущую установленную
версию и её данные до успешной проверки кандидата.

Последняя команда проверяет реальный standalone backend: typed SDK, pinned PAL
парсеры и worker import, architecture/signature, лицензии и совпадение исходников
с embedded fingerprint. Она не читает ключи, не обращается к провайдерам и не заменяет
практическую проверку нового чата. `0.1.0` без fingerprint недостаточно для идентификации
запущенной сборки; receipt формируется до freezing из явных публичных входов.

Для уже установленной беты:

```sh
"$HOME/Applications/Pair.app/Contents/MacOS/PairCore" doctor
"$HOME/Applications/Pair.app/Contents/MacOS/PairCore" check-release
```

Для подключения без панели предназначены `integrate-codex` / `integrate-claude`.
Само подключение изменяет клиентскую конфигурацию только в части Pair.

## Удалить подключение / откатить

Сначала дождитесь нужных задач либо отмените **конкретные** задачи Pair. Затем:

```sh
"$HOME/Applications/Pair.app/Contents/MacOS/PairCore" uninstall-codex
"$HOME/Applications/Pair.app/Contents/MacOS/PairCore" uninstall-claude
```

Удаление снимает только Pair MCP и принадлежащий установке неизменённый skill.
Если владелец изменил skill/entry, команда должна сохранить изменения и сообщить
о ручном восстановлении. Нельзя восстанавливать весь старый `config.toml` или
`.claude.json`: так можно потерять другие подключения, добавленные позже.

Настройки, история заданий и Keychain сохраняются при отключении. Ключ удаляется
явной кнопкой в **Подключениях**; удаление app само по себе ключ не стирает. Для
отката приложения используйте сохранённую предыдущую `Pair.app` в той же стабильной
папке, проверьте build identity и переподключите только Pair. Не удаляйте каталоги
Codex/Claude, другие плагины или соседние службы.

Закрытие панели намеренно не завершает backend. Горячее обновление работающего
демона в бете не автоматизировано: перед сменой сборки завершите задания и адресно
перезапустите только принадлежащий Pair backend. Не заменяйте app во время работы
и не завершайте все процессы Codex/Claude/PairCore подряд.
